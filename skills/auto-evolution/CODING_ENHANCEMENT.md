# Coding Enhancement Config

> 让 OpenClaw 成为你的专业编程助手

## 适用场景

- 你的职业是程序员
- 需要深度编程辅助
- 希望自动学习编程模式

---

## 编程增强配置

### 1. 添加到 HEARTBEAT.md

```markdown
## 编程助手专属检查

每次心跳时:

1. 扫描最近的代码变更
   - 检查 workspace/ 下的代码文件
   - 识别新的模式和问题

2. 代码质量监控
   - 检查是否有 TODO/FIXNEED
   - 识别重复代码模式
   - 发现可能的性能问题

3. 学习代码模式
   - 记录成功的解决方案
   - 更新 CODING_PATTERNS.md
   - 建议改进机会

4. 主动建议
   - 如果发现问题, 主动报告
   - 提供具体的改进建议
```

### 2. 添加到 MEMORY.md

```markdown
# Programming Context

## 专业领域

- **职业**: 程序员
- **需求**: 深度编程辅助

## 编程偏好

- 代码风格: [你的偏好]
- 测试策略: [TDD/BDD/etc]
- 文档习惯: [详细/简洁]
- 提交风格: [频繁/谨慎]

## 技术栈

- 主要语言: [TypeScript/Python/etc]
- 框架: [React/Next.js/etc]
- 数据库: [PostgreSQL/etc]
- 工具: [Git/Docker/etc]
```

### 3. 配置增强

```json5
// config.json5
{
  agents: {
    defaults: {
      // 编程增强心跳
      heartbeat: {
        every: "15m", // 更频繁的检查
        prompt: `
          ## 编程助手心跳

          1. 代码扫描:
             - 检查最近的代码变更
             - 识别模式和反模式
             - 发现改进机会

          2. 质量监控:
             - 检查 TODO/FIXNEED
             - 发现重复代码
             - 性能警告

          3. 学习更新:
             - 更新 CODING_PATTERNS.md
             - 记录成功的解决方案

          如果发现问题, 报告。 否则回复 HEARTBEAT_OK.
        `,
      },

      // 编程专属 compaction
      compaction: {
        memoryFlush: {
          enabled: true,
          systemPrompt: "编程会话即将压缩。 保存所有代码模式和学习成果.",
          prompt: `
            ## 代码知识保存

            在压缩前保存:
            - 新的代码模式 → CODING_PATTERNS.md
            - 成功的解决方案 → SOLUTIONS.md
            - 错误教训 → LESSONS_LEARNED.md

            回复 NO_REPLY 如果没有新知识.
          `,
        },
      },
    },
  },
}
```

## 使用建议

### 工作流程

1. **编码时**: 正常工作, OpenClaw 会在后台学习
2. **提交前**: 说 "代码审查" 获取审查报告
3. **遇到问题**: 说 "debug" 获取帮助
4. **日常**: 查看每日编程报告

### 最佳实践

- 让 OpenClaw 观察你的编码过程
- 定期查看 CODING_PATTERNS.md
- 关注 OpenClaw 的改进建议
- 保持 MEMORY.md 更新
