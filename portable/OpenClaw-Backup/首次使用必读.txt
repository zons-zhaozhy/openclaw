🎉 欢迎使用 OpenClaw 便携版！

🚀 极简启动流程（只需 3 步）

第 1 步：双击启动文件
  macOS:   双击「启动.sh」或「启动.command」
  Windows: 双击「启动.bat」

第 2 步：选择启动模式
  1️⃣  U盘快速启动（推荐）
      → 数据保存在 U 盘
      → 拔出 U 盘数据随身带走

  2️⃣  安装到电脑
      → 程序安装到本地硬盘
      → 自动创建桌面快捷方式
      → 运行速度更快

第 3 步：配置 AI 模型（首次使用）
  程序会自动提示你选择 AI 提供商：

  • OpenAI (ChatGPT)    - 推荐，功能强大
  • 智谱 AI (GLM)       - 中文优秀，国内可用
  • 月之暗面 (Moonshot) - 长文本处理强
  • Claude (Anthropic)  - 安全可靠

  输入你的 API Key 即可开始使用！

第一次启动后，以后只需：
  1. 双击启动文件
  2. 选择模式
  3. 自动打开浏览器，开始使用

📋 系统要求

✅ Node.js 18 或更高版本

检查方法：
  macOS/Linux: 打开终端，输入 node -v
  Windows:     打开 CMD，输入 node -v

如果未安装：
  👉 https://nodejs.org/zh-cn/
  下载 LTS 版本，双击安装即可

💡 使用技巧

✅ 网页版功能
  • 多标签对话
  • Markdown 实时渲染
  • 代码高亮
  • 对话历史保存
  • 导出功能

✅ 快捷键
  Ctrl+Enter  发送消息
  Ctrl+N      新建对话
  Ctrl+/      显示帮助

✅ 数据备份
  U盘模式：复制「数据」文件夹到电脑
  安装模式：数据在 C:\Users\你的用户名\.openclaw-portable\数据

──────────────────────────────────────────────────

🔒 安全提示

✅ 推荐
  • 使用加密 U 盘
  • 定期备份「数据」文件夹
  • 不要在公共电脑保存敏感对话

❌ 避免
  • 直接拔出 U 盘（先关闭程序）
  • 在不受信任的电脑使用
  • 长期不备份对话记录

❓ 常见问题

Q: 启动时提示"未安装 Node.js"？
A: 访问 https://nodejs.org/zh-cn/ 下载安装

Q: 浏览器没有自动打开？
A: 手动访问 http://localhost:18789

Q: 忘记选择哪个 AI 模型？
A: 推荐「智谱 AI」或「OpenAI」，都有免费额度

Q: API Key 在哪里看？
A: 登录对应平台官网，在 API Keys 页面获取

Q: 如何更换 AI 模型？
A: 编辑「数据/config/keys.json」文件

Q: 数据会丢失吗？
A: U盘模式：数据在 U 盘，安全
   安装模式：数据在电脑，更安全

Q: 可以同时在多台电脑使用吗？
A: 可以！U盘模式插哪台都能用

Q: 如何完全卸载？
A: 删除整个 OpenClaw-Portable 文件夹即可
   安装版还需删除桌面快捷方式
