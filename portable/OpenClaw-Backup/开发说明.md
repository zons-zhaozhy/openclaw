## 🚀 分发流程

### 开发者操作

```bash
# 1. 构建项目
pnpm build

# 2. 复制到便携目录
mkdir -p portable/OpenClaw-Portable/openclaw
cp -r dist portable/OpenClaw-Portable/openclaw/
cp package.json portable/OpenClaw-Portable/openclaw/

# 3. 运行测试
cd portable/OpenClaw-Portable
./测试便携版.sh

# 4. 打包分发
cd ../../
./scripts/打包便携版.sh
```

### 用户操作

```
1. 下载 OpenClaw-便携版-v2026.2.9.tar.gz
2. 解压（macOS: 双击，Windows: 7-Zip）
3. 双击「启动.sh」或「启动.bat」
4. 选择模式 → 配置 AI → 开始使用
```

## 🔧 技术特点

### 1. 零配置启动

- 自动检测系统环境
- 自动查找程序文件
- 自动创建数据目录

### 2. 智能配置向导

- 交互式 AI 提供商选择

### 3. 双模式支持

- **U盘模式**：数据在 U 盘，随身携带
- **安装模式**：数据在本地，速度更快

### 4. 跨平台兼容

- macOS（支持 Intel + Apple Silicon）
- Windows（支持 Windows 10+）
- Linux（通用支持）
