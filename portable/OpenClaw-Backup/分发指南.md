# OpenClaw 便携版 - 分发指南

## 🎯 推荐分发方式

### 方式 1：直接分发文件夹 ⭐️ 推荐

**最简单！用户无需任何操作**

```
分发步骤：
1. 构建项目: pnpm build
2. 复制整个 OpenClaw-Portable 文件夹
3. 发给用户（U盘/网盘/邮件）

用户使用：
1. 收到 OpenClaw-Portable 文件夹
2. 双击「启动.sh」或「启动.bat」
3. 开始使用！
```

**优点：**

- ✅ 零门槛，双击即用
- ✅ 无需解压
- ✅ 可直接放到 U 盘

**适用场景：**

- U 盘分发
- 局域网共享
- 云盘同步文件夹

---

### 方式 2：ZIP 压缩包（备选）

**适合网络分发**

```bash
# macOS/Linux
cd portable
zip -r OpenClaw-便携版.zip OpenClaw-Portable \
  -x "*.DS_Store" \
  -x "*/数据/*" \
  -x "*/测试便携版.sh"

# Windows
# 右键 OpenClaw-Portable → 发送到 → 压缩文件夹
```

**用户使用：**

1. 下载 ZIP 文件
2. 双击解压（系统自带）
3. 进入文件夹，双击启动

**优点：**

- ✅ 单文件，方便传输
- ✅ macOS/Windows 自带解压
- ✅ 适合邮件/网盘分发

**适用场景：**

- GitHub Releases
- 网盘下载
- 邮件附件

---

## 📋 分发检查清单

打包前确保：

- [ ] 已运行 `pnpm build`
- [ ] 已复制 dist/ 到 OpenClaw-Portable/openclaw/
- [ ] 测试脚本通过：`./测试便携版.sh`
- [ ] 删除测试数据（数据/ 文件夹）
- [ ] 检查文件大小（应该 <50MB）

## 🚀 快速分发脚本

### macOS/Linux

```bash
# 1. 构建
pnpm build

# 2. 复制程序
mkdir -p portable/OpenClaw-Portable/openclaw
cp -r dist portable/OpenClaw-Portable/openclaw/
cp package.json portable/OpenClaw-Portable/openclaw/

# 3. 测试
cd portable/OpenClaw-Portable
./测试便携版.sh

# 4. 分发
# 方式 A: 直接复制整个文件夹
# 方式 B: 打包 ZIP
cd ..
zip -r OpenClaw-便携版.zip OpenClaw-Portable
```

### Windows

```cmd
# 1. 构建
pnpm build

# 2. 复制程序
# 手动复制 dist/ 到 portable/OpenClaw-Portable/openclaw/

# 3. 测试
cd portable\OpenClaw-Portable
测试便携版.bat

# 4. 压缩
# 右键 OpenClaw-Portable → 发送到 → 压缩文件夹
```

## ❓ 常见问题

**Q: 用户抱怨文件太多？**
A: 提供 ZIP 版本，双击解压即可

**Q: 需要加密分发吗？**
A: 可以，用 7-Zip 加密：

```bash
7z a -p密码 OpenClaw-便携版.7z OpenClaw-Portable
```

**Q: 如何更新版本？**
A: 用户只需替换 openclaw/ 文件夹，数据自动保留

**Q: 需要签名吗？**
A: macOS 可能需要，Windows 通常不需要
