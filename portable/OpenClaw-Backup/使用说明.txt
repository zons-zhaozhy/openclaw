   OpenClaw 便携版 - 使用说明
════════════════════════════════════════

✨ 欢迎使用 OpenClaw 便携版！

这是专为中文用户优化的版本，支持：
  ✅ 完全离线使用（需配置本地模型）
  ✅ 网页界面（Web UI）
  ✅ 命令行界面（TUI）
  ✅ 数据随身携带

────────────────────────────────────────

🚀 快速开始

1️⃣ 双击「启动.sh」文件

2️⃣ 选择模式：
   • 网页版（推荐）- 浏览器访问 http://localhost:3000
   • 命令行版     - 直接在终端对话
   • 生成密钥     - 获取登录密码

3️⃣ 开始使用！

────────────────────────────────────────

📁 文件说明

启动.sh          ← 双击这个开始使用
使用说明.txt     ← 你正在看的文件
数据/            ← 对话记录和配置
openclaw/        ← 程序文件（勿删）

────────────────────────────────────────

⚙️ 系统要求

• macOS 或 Linux
• Node.js 18 或更高版本
  （如未安装，访问: https://nodejs.org/zh-cn/）

────────────────────────────────────────

🌐 网页版功能

✅ 多标签对话
✅ Markdown 实时渲染
✅ 代码高亮
✅ 对话历史
✅ 导出功能

────────────────────────────────────────

💡 使用提示

• 首次使用会提示配置 AI 模型
• 数据保存在「数据」文件夹
• 拔出 U 盘前先关闭程序
• 支持云端 API 和本地模型

────────────────────────────────────────

🔗 帮助与支持

官方文档: https://docs.openclaw.ai
中文社区: https://docs.openclaw.ai/zh-CN
问题反馈: https://github.com/openclaw/openclaw/issues

────────────────────────────────────────

🔒 安全建议

• 不要在公共电脑保存敏感对话
• 定期备份「数据」文件夹
• 使用加密 U 盘更安全
